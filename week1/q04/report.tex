  \section{Result}

  The average latency of requests is defined by equation \eqref{eq:latency}:

  \begin{equation}
      \bar{L} = \frac{1}{n} \sum_{i=1}^{n} L_i
      \label{eq:latency}
  \end{equation}

  where $L_i$ is the latency of the $i$-th request and $n$ is the total number
  of requests. The result of this experiment is shown in Table \ref{tab:tools}.
