 # 协作材料改写（q11）

  ## Issue

  --name 传入只含空白字符的值时仍输出问候语并以 0 退出

  环境：待确认（操作系统、Python 版本、安装方式均未提供）。

  复现命令：安装 greetlab 包后，运行 sdt-greet --name " "

  期望结果：程序拒绝只含空白字符的姓名，报错并以非零退出码结束，不输出问候语。

  实际结果：输出 Hello, !，并以退出码 0 结束。

  ## 提交信息

  拒绝空白姓名并以非零退出码结束

  问题：--name 传入只含空白字符的值时，程序仍输出 Hello, ! 并以退出码 0
  结束，调用方会误判执行成功。

  解决方案：解析参数后校验姓名，若去除首尾空白后为空，则通过 p.error() 报错，以退出码 2
  结束进程，不再输出问候语。

  ## 评审意见

  Blocking：parse_args 之后未对 --name 做非空校验——只含空白字符的输入（如 "
  "）会静默输出 Hello, ! 并以退出码 0
  结束，调用方会误判执行成功、输入错误被掩盖。建议解析后校验 a.name.strip()，为空则改用
  p.error() 报错，使程序以退出码 2 结束。
